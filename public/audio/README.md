# Demo recordings

Drop the two demo call recordings here with these exact filenames:

- `demo-english.mp3` : English sample call (new patient books a consultation)
- `demo-arabic.mp3` : Arabic sample call (after-hours WhatsApp caller, answered and booked)

The players on /demo detect the files automatically: while a file is
missing its player shows a "Recording coming soon" state; once the file
exists the player activates. No code change or flag needed.

Keep files small (target under 2 MB, mono, 96 to 128 kbps MP3): the
page's audience is mobile WhatsApp traffic.
